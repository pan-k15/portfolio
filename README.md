## Project Info Format

Each `info.md` file usually includes:

- Project overview
- Project type and status
- GitHub repository link
- Description
- Images or recommended image slots
- Features
- Technical details, packages, modules, or workflow
- Notes

## Images

Some projects already include images copied from their source repositories. Other projects include recommended image slots so screenshots can be added later.

Suggested image folder pattern:

```text
project_x/
|-- info.md
`-- images/
    |-- screenshot-1.png
    |-- demo.png
    `-- preview.png
```
